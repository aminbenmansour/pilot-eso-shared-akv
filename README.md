# pilot-eso-shared-akv

Pilot configuration for implementing a shared Azure Keyvault with ESO through RBAC rules and role_assignment(s)

## Terraform module: `eso-app-identity`

Per application, the module creates:

- a user-assigned managed identity,
- a federated identity credential bound to the AKS OIDC issuer and the External Secrets Operator service account,
- a `Key Vault Secrets User` role assignment on the shared Key Vault, conditioned on the `<app>--` secret prefix,
- the Kubernetes service account, annotated with the identity's `client-id` and `tenant-id` so that ESO can exchange its projected token for an Entra ID token (workload identity).

```hcl
module "glitchtip_identity" {
  source = "./terraform/modules/eso-app-identity"

  app                 = "glitchtip"
  env                 = "dev"
  location            = azurerm_resource_group.this.location
  resource_group_name = azurerm_resource_group.this.name
  namespace           = "glitchtip"
  key_vault_id        = azurerm_key_vault.this.id

  oidc_issuer_url = data.terraform_remote_state.aks.outputs.oidc_issuer_url
}
```

The module relies on the `kubernetes` provider, which is configured in the root module and defaults to the current kubeconfig context. Make sure that context points at the target AKS cluster (`az aks get-credentials ...`) and that the application namespace already exists.

The service account name defaults to `eso-<app>` and can be overridden with `service_account_name`. To keep managing it elsewhere (for example by GitOps), set `manage_service_account = false` and annotate it yourself with the `client_id` and `tenant_id` outputs.

If the service account was previously created from the removed manifest, delete it or import it before applying:

```bash
kubectl -n glitchtip delete sa eso-glitchtip
# or
tofu import 'module.glitchtip_identity.kubernetes_service_account_v1.app[0]' glitchtip/eso-glitchtip
```

## Kubernetes manifests

`kubernetes/manifests` contains only the `SecretStore` and `ExternalSecret`. The service account is generated by Terraform, see above.
